# Datos locales

`local/originals/` conserva el ZIP de Vision, tres Excel QC completados y la copia original del manifiesto. Toda la carpeta `local/` está excluida de Git; sus archivos se mantienen únicamente para trabajo local.

El manifiesto es **dummy data autorizado para demostración por el propietario**. Su copia publicable está en [`examples/reception/SmartFruit_reception_manifest_demo.csv`](../examples/reception/SmartFruit_reception_manifest_demo.csv), conservando el contenido del archivo proporcionado. No se incluyen los Excel QC completados. Los JSON de demo se conservan separadamente en `examples/vision/`.

El inventario de originales `docs/source_inventory.json` es un archivo local excluido de Git. No se establece automáticamente una relación entre el manifiesto dummy, los reportes históricos y las fotografías de evaluación.
